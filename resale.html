Connect BidFTA

BidFTA's data isn't reachable straight from a browser (no CORS). A tiny free Cloudflare Worker fixes that. No API key needed.

Deploy bidfta-worker.js from this repo to a free Cloudflare Worker, then paste its URL here. Full steps in BIDFTA_SETUP.md.
Direct mode calls BidFTA with no proxy. It usually fails in the browser (blocked by CORS) but is here as a fallback if you run the page somewhere without that restriction. If loads fail, switch back to Proxy.
